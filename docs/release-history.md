release-please maintains the canonical
[CHANGELOG.md](https://github.com/jbcom/maze-core/blob/main/CHANGELOG.md), version metadata, tags and
GitHub Releases. Published releases use npm provenance and the project supports the latest `0.x` line.

A change to what a seed produces is a breaking change, whatever it does to the types: use a `!` or a
`BREAKING CHANGE:` footer.
